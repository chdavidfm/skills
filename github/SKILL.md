# github — el músculo de toda la vida

GitHub de `chdavidfm` no es “el repo de Renovo”. Es el sitio donde vive **código + skills portables + lab**. El cerebro sigue siendo el vault. El CRM sigue siendo Notion.

## Leyes

1. Un hecho, un sitio. No subas el vault. No subas Bella, secretos, ARE, IBAN.
2. Repo nuevo **sólo** si hay código o skills que no caben en los cuatro de arriba. No 30 repos de carpetas.
3. Org `Renovo` = vitrina de producto, cuando David la cree en la web. Hasta entonces el usuario `chdavidfm` es la casa.
4. Source de Renovo **privado**. Ayuda = invitar, no hacer público el SaaS.
5. CI que falle si mientes. Releases en `v*`. CODEOWNERS. Dependabot. Custom agent en `.github/agents/` cuando el repo es de código.
6. Tras merge que importe a la vida: skill `pulso` si tocó Renovo; Diario 3 frases siempre.

## Cuando David pega un GitHub / skill pack viral

Destila: estándar `SKILL.md` (agentskills.io) = sí. Código GPL de otro (OpenHuman) = no se pega. Instalar un segundo OS de escritorio = no. Extrae el **patrón**, escribe skill propia.
